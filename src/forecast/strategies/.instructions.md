# Forecast Strategies — Detailed Algorithm Reference

Compact reference for thesis-vs-code comparison.  All architectures are in
`src/forecast/strategies/`.  Shared training/prediction pipeline lives in
`base_keras.py` (applies to all Keras models).

---

## Shared Keras Pipeline (`base_keras.py`)

All neural strategies inherit `KerasTimeSeriesBaseStrategy` and share:

| Step | Detail |
|------|--------|
| Scaling | `RobustScaler` fitted **only on train split** (no leakage); separate scaler for target vs. features |
| Sequences | Sliding window `(n_windows, look_back, n_features)` |
| Clip guard | Input clipped to ±3.0 σ after scaling |
| Callbacks | `EarlyStopping(patience=10, restore_best)` + `ReduceLROnPlateau(factor=0.5, patience=5)` — both active unless `use_lr_scheduler=False` |
| Loss / compile | `Adam`, loss=`mse`, metrics=`['mae','mse']` |
| Backtest mode | Rolling one-step: first `look_back` rows are warm-up; predictions start at `[look_back:]` |
| Schedule mode | Recursive multi-step: predict 1, feed back, repeat for `forecast_horizon` |
| Rolling retrain | Optional sliding-window retraining (disabled by default); **excluded** for Hussain variants and tree models |

Subclasses implement only `build_model(input_shape, **kwargs)`.

## LSTM (`lstm_strategy.py`)

**Class**: `LSTMModelStrategy`  
**Registry key**: `"lstm"` / `"hussain_lstm"`

```
Sequential:
  Input(look_back, 1)
  → LSTM(64, return_sequences=True, activation)
  → Dropout(dropout_rate)
  → LSTM(32, activation)
  → Dropout(dropout_rate)
  → Dense(output_steps)
```

**Default params** (from `execute_lstm`):

| Param | Our models | Hussain variant |
|-------|-----------|-----------------|
| `epochs` | 100 | 100 |
| `batch_size` | 32 | 32 |
| `look_back` | 28 (`LOOK_BACK_DAYS`) | `max(14, h)` |
| `learning_rate` | 0.001 | 0.001 |
| `dropout_rate` | 0.2 | 0.2 |
| `activation` | `'relu'` | `'relu'` |
| `use_log_transform` | `True` | `True` |

## Transformer (`transformer_strategy.py`)

**Class**: `TransformerModelStrategy`  
**Registry key**: `"transformer"`

```
Functional API:
  Input(look_back, 1)
  → [× num_transformer_blocks]:
      LayerNorm(ε=1e-6)
      → MultiHeadAttention(key_dim=head_size, num_heads, dropout)
      → Dropout → Add (residual)
      → LayerNorm(ε=1e-6)
      → Dense(ff_dim, relu)
      → Dropout
      → Dense(d_input)   # projects back to input width
      → Add (residual)
  → GlobalAveragePooling1D
  → Dense(mlp_units[0]=128, relu)
  → Dropout(mlp_dropout)
  → Dense(1)
```

**Default params** (from `execute_transformer`):

| Param | Value |
|-------|-------|
| `head_size` | 128 |
| `num_heads` | 4 |
| `ff_dim` | 4 |
| `num_transformer_blocks` | 2 |
| `dropout` | 0.1 |
| `mlp_dropout` | 0.1 |
| `look_back` | 28 |
| `epochs` | 100 |
| `batch_size` | 32 |
| `learning_rate` | 0.001 |
| `use_log_transform` | `True` |

## Hybrid LSTM-Transformer (`hybrid_strategy.py`)

**Class**: `HybridTransformerLSTMModelStrategy`  
**Registry key**: `"hybrid"`

```
Functional API:
  Input(look_back, 1)

  [Encoder]
  → LSTM(d_model, return_sequences=True)
  → MultiHeadAttention(key_dim=d_model, num_heads, dropout)
  → Add (residual skip from LSTM output)          ← residual present
  → LayerNorm(ε=1e-6)

  [Decoder]
  → LSTM(d_model, return_sequences=True)
  → MultiHeadAttention(key_dim=d_model, num_heads, dropout)
  → Add (residual skip from LSTM output)          ← residual present
  → LayerNorm(ε=1e-6)

  [Head]
  → Flatten → Dense(1)
```

**Default params** (from `execute_hybrid`):

| Param | Value |
|-------|-------|
| `d_model` | 128 |
| `num_heads` | 4 |
| `dropout` | 0.1 |
| `look_back` | 28 |
| `epochs` | 100 |
| `batch_size` | 32 |
| `learning_rate` | 0.001 |
| `use_log_transform` | `True` |

## Hussain Transformer (`hussain_transformer_strategy.py`)

**Class**: `HussainTransformerModelStrategy`  
**Registry key**: `"hussain_transformer"`  
**Reference**: Hussain et al. (2025) *Sci Rep* 15, 13555 — Fig. 3, Eqs. 8–12

```
Functional API:
  Input(look_back, 1)
  → Dense(encoding_dim=64, relu)        [Eq. 8]
  → MultiHeadAttention(key_dim=64, num_heads=4, dropout=0.2)  [Eq. 9]
  → GlobalAveragePooling1D              [Eq. 10]   ← channels_last (temporal)
  → Dense(output_steps)                 [Eq. 12]
```

**Key deviations vs. `TransformerModelStrategy`**:
- No residual connections
- No LayerNormalization
- No feed-forward sub-block
- No MLP head (direct Dense after pooling)
- Single attention layer (not stacked)
- `GlobalAveragePooling1D` uses `channels_last` (pools over timesteps)

**Default params** (from `execute_hussain_transformer`):

| Param | Value |
|-------|-------|
| `encoding_dim` | 64 |
| `num_heads` | 4 |
| `key_dim` | 64 |
| `dropout` | 0.2 |
| `look_back` | `max(14, forecast_horizon)` |
| `epochs` | 100 |
| `batch_size` | 32 |
| `learning_rate` | 0.001 |

**Article note**: Paper's reported "MSE" values are numerically close to their
MAE — believed to be RMSE mislabelled as MSE.  Use RMSE column for comparison.

## Hussain Hybrid (`hussain_hybrid_strategy.py`)

**Class**: `HussainHybridModelStrategy`  
**Registry key**: `"hussain_hybrid"`  
**Reference**: Hussain et al. (2025) *Sci Rep* 15, 13555 — Fig. 4

```
Functional API:
  Input(look_back, 1)

  [Encoder]
  → LSTM(d_model=128, return_sequences=True)
  → Sinusoidal PE (Vaswani et al. 2017 Eq. 3)     ← added as Lambda layer
  → MultiHeadAttention(key_dim=d_model, num_heads=4, dropout=0.2)
  → LayerNorm(ε=1e-6)                              ← NO Add/residual
  → Dropout(0.2)

  [Decoder]
  → LSTM(d_model=128, return_sequences=True)
  → Sinusoidal PE
  → MultiHeadAttention(key_dim=d_model, num_heads=4, dropout=0.2)
  → LayerNorm(ε=1e-6)                              ← NO Add/residual
  → Dropout(0.2)

  [Head]
  → Flatten → Dense(output_steps)
```

**Key deviations vs. `HybridTransformerLSTMModelStrategy`**:
- **No residual connections** (`Add` skip-paths removed — article Fig. 4)
- Explicit `Dropout` after each `LayerNorm`
- **Sinusoidal positional encoding** injected between LSTM and MHA (both encoder and decoder)
- `dropout=0.2` (vs. 0.1 in standard Hybrid)

**Sinusoidal PE formula** (Vaswani 2017 Eq. 3):
```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

**Default params** (from `execute_hussain_hybrid`):

| Param | Value |
|-------|-------|
| `d_model` | 128 |
| `num_heads` | 4 |
| `dropout` | 0.2 |
| `look_back` | `max(14, forecast_horizon)` |
| `epochs` | 100 |
| `batch_size` | 32 |
| `learning_rate` | 0.001 |

## LightGBM (`lightgbm_strategy.py`)

**Class**: `LightGBMModelStrategy`  
**Registry key**: `"lightgbm"`

- API: `lgb.train()` with `lgb.Dataset`
- Features: tabular (lags + rolling means + calendar) — **no sequences**
- `select_dtypes(exclude=['object','string'])` applied before fitting
- Train/test split: chronological by `split_date`; fallback 90/10 row split
- Early stopping: `lgb.early_stopping(early_stopping_rounds)` callback

**Default params** (from `execute_lightgbm`):

| Param | Value |
|-------|-------|
| `num_leaves` | 31 |
| `learning_rate` | 0.02 |
| `max_depth` | 8 |
| `early_stopping_rounds` | 200 |
| `nthread` | -1 (all cores) |
| `use_log_transform` | `False` |

**Metrics reported**: SMAPE, MAPE, Accuracy (= 100 − MAPE); note: `np.expm1` applied to predictions and actuals before SMAPE even when `use_log_transform=False` (legacy — safe when no log was applied: expm1(y_pred) ≈ y_pred + 1 is incorrect; verify in code).

## XGBoost (`xgboost_strategy.py`)

**Class**: `XGBoostModelStrategy`  
**Registry key**: `"xgboost"`

- API: `XGBRegressor(objective="reg:squarederror")`
- Auto one-hot encodes `plug_in_weekday` → `plug_in_weekday_0..6`
- Features resolved from fitted model at predict time
- Train/test: `train_test_split` (random) when no `split_date`; chronological when `split_date` provided

**Default params** (from `execute_xgboost`):

| Param | Value |
|-------|-------|
| `random_state` | 16 |
| `test_size` | 0.20 |
| `use_log_transform` | `False` |

**Metrics reported**: MAE, MAPE, Accuracy.
