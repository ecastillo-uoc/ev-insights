# Utils Module — Instructions

## Purpose

Shared utilities: centralized logging, constants, console output, path normalization, output serialization, and date/time helpers.

## File Inventory

| File | Role |
|------|------|
| `logger.py` | `Logger` class — rotating file handlers, console output, optional email alerts |
| `constants.py` | Pure data constants: `DEFAULT_DATAFRAME_COLUMNS`, `DEFAULT_EV_DATAFRAME_COLUMNS`, `DEFAULT_CHARGING_STATION_DATAFRAME_COLUMNS`, `DEFAULT_CHARGING_POINT_TYPES`, `DEFAULT_CONNECTOR_TYPES`, `CONNECTOR_TYPE_ALIASES` |
| `db_config.py` | DB-related functions: `_get_db_config_from_env()`, `_query_rows()`, `get_charging_point_types_from_db()`, `get_connector_types_from_db()`, `get_dataframe_columns_from_db()` + module-level lazy vars (`DATAFRAME_COLUMNS`, `CHARGING_POINT_TYPES`, `CONNECTOR_TYPES`) |
| `console.py` | `Colors` class (ANSI SGR codes for log highlighting), `rich.Console` instance, and helper functions (`log_success`, `log_warning`, `log_error`, `log_info`) |
| `output.py` | `save_results_to_json(results, output_dir, name)` — shared JSON output used by Admin, Analysis, and Forecast base classes |
| `path_utils.py` | `normalize_path(path_str) → Path` — wraps `PureWindowsPath(...).as_posix()` for cross-platform path handling |
| `date_utils.py` | Date/time utility functions |

## Logger (`logger.py`)

- Rotating file handler: 100 MB max, 10 backups.
- Console + file output with configurable formatters.
- Error-level email notifications via SMTP (optional).
- Framework-wide: all modules use `logging.getLogger('<area>')`.

## Console (`console.py`)

- `Colors` class provides ANSI SGR escape codes (`Colors.GREEN`, `Colors.BLUE`, `Colors.YELLOW`, etc.) used in log traces for highlighting.
- `rich.Console` instance available for enhanced terminal formatting.
- Helper functions (`log_success`, `log_warning`, etc.) combine `rich` formatting with structured output.

## Constants (`constants.py`)

Pure data with no side effects or imports:
```python
DEFAULT_DATAFRAME_COLUMNS                     # Core charging session fields
DEFAULT_EV_DATAFRAME_COLUMNS                  # EV specifications
DEFAULT_CHARGING_STATION_DATAFRAME_COLUMNS    # Station metadata
DEFAULT_CHARGING_POINT_TYPES                  # private_domestic, private_workplace, public
DEFAULT_CONNECTOR_TYPES                       # T3, T2, TE, CHAdeMO, Combo
CONNECTOR_TYPE_ALIASES                        # Maps variant names → standard codes
```

## DB Config (`db_config.py`)

- Reads DB connection parameters from environment variables.
- Fetches valid connector types and charging point types from the database.
- Falls back to `constants.py` defaults when DB is unavailable.
- Module-level lazy variables: `DATAFRAME_COLUMNS`, `CHARGING_POINT_TYPES`, `CONNECTOR_TYPES`.

## Path Utils (`path_utils.py`)

- `normalize_path(path_str)` centralizes the `PureWindowsPath(...).as_posix()` pattern.
- Config files may contain Windows-style backslash paths from the original development environment.
- Used in `__main__.py`, `service.py`, `interface.py`, and `file_interface.py`.

## Conventions

- All modules import `logging.getLogger(name)` — do not create new `Logger` instances directly.
- Column lists in `constants.py` define the canonical schema — changes here affect ingestion and analysis.
- `CONNECTOR_TYPE_ALIASES` is used during data normalization.
- Debug traces use `[ClassName.method]` prefixes and `Colors.XXX` ANSI highlighting for clarity.

## Refactoring Considerations

- **DB config via env vars**: Good practice but currently mixed with `psycopg2` direct usage — should go through the interface.

## Notes

- **`date_utils.py`** contains a single function: `utc_to_decimal_hours_minutes(utc_time)` — converts a `datetime` to decimal hours (e.g. 10:30 → 10.5).  Used by session-level data strategies.
