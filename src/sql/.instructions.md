# SQL Module — Instructions

## Purpose

Centralized SQL schema, queries, and seed data for PostgreSQL. All database interactions reference this module for query strings and schema definitions.

## File Inventory

```
sql/
└── postgresql/
    ├── sql_query.py       # All SQL queries as string constants
    ├── schema.sql         # Database schema DDL
    ├── schema.pgerd       # ERD diagram source
    ├── schema.png         # Visual ERD
    ├── seed/              # Sample data for initialization
    └── raw_queries/       # Additional standalone queries
```

## Schema (Key Tables)

| Table | Purpose |
|-------|---------|
| `Dataset` | Metadata about ingested data sources |
| `ChargingStation` | Charging infrastructure details |
| `ChargingSession` | Individual charge event records |
| `User` | EV user information |
| `ElectricVehicle` | Vehicle specifications |
| `ChargingStationForecast` | Station-level prediction results |
| `UserForecast` | User-level prediction results |

## Query Organization (`sql_query.py`)

Queries are grouped by category:
- **Ingestion**: `insert_charging_sessions`, `insert_users`, `insert_electric_vehicles`, `insert_charging_stations`
- **Retrieval**: `get_dataset_list`, `get_all_countries`, `get_years_filtered`, `dynamic_query`
- **Forecasting**: `insert_user_forecast`, `insert_charging_station_forecast`, `get_user_prediction`
- **Metadata**: `get_dataset_id_by_name`, `check_column_existence`

## Conventions

- Queries are plain string constants (not ORM).
- Parameterized queries use `%s` placeholders for `psycopg2`.
- Schema changes require updating both `schema.sql` and relevant queries.

## Refactoring Considerations

- **No migration system**: Schema changes are applied by recreating the database. Schema recreation is the accepted workflow for this project.
- **Query string management**: 200+ queries in a single file is hard to navigate. Consider splitting into domain-specific modules (`ingestion_queries.py`, `forecast_queries.py`, `analysis_queries.py`).
- **Verify parameterization**: Ensure no queries use f-strings or `.format()` with user input — critical for SQL injection prevention.
- **Schema documentation**: `schema.pgerd` and `schema.png` may be outdated after TFM additions. Regenerate.
