# Data Module — Instructions

## Purpose

Data Access Layer (DAL): constants, SQL query functions, and dataset configurations
shared across forecasting and analysis modules.  No ML or thesis-specific logic here.

## File Inventory

| File | Role |
|------|------|
| `constants.py` | COVID gap boundaries and `EXCLUDE_COVID_DATA` flag |
| `data_fetcher.py` | Query functions returning `pd.DataFrame` from PostgreSQL |

---

## Constants (`constants.py`)

```python
COVID_START = '2020-08-05'   # First day of 105-day zero-energy gap in ACN datasets
COVID_END   = '2020-11-17'   # Last day of zero-energy gap
EXCLUDE_COVID_DATA = True    # Global flag — pipeline reads this to decide exclude_range
```

**Context**: ACN_JPL and ACN_Caltech datasets show 105 consecutive zero-energy days
(Aug–Nov 2020) due to COVID-19 lockdowns.  These are `asfreq` fill zeros, not real
observations.  Training data excluding this range is controlled per-experiment via
`exclude_range` in `get_dataset_config()`.

---

## Data Fetcher Functions (`data_fetcher.py`)

All functions take `db_config: dict` (optional; falls back to `DEFAULT_DB_CONFIG`)
and return `pd.DataFrame`.  Use SQLAlchemy engine internally.

| Function | Aggregation | Index | Use |
|----------|-------------|-------|-----|
| `fetch_daily_energy_for_forecast(dataset_name, split_date, db_config, site_name, exclude_covid)` | Daily SUM energy, COUNT sessions | DatetimeIndex | Forecast pipeline |
| `fetch_dataset_energy_trends(dataset_name, db_config, site_name)` | Daily SUM energy, AVG session duration, COUNT sessions/stations | DatetimeIndex | EDA / analysis |
| `fetch_dataset_charges_trends(dataset_name, db_config)` | Daily COUNT sessions | DatetimeIndex | EDA |
| `fetch_dataset_plug_ins(dataset_name, db_config)` | Raw sessions (plug_in_datetime, energy_supplied, …) | integer | Session-level analysis |

### `fetch_daily_energy_for_forecast`

Primary function for the forecast pipeline:
- Filters by `dataset_name` and optional `site_name`
- Excludes COVID gap when `exclude_covid=True` (removes rows in `[COVID_START, COVID_END]`)
- Returns daily DataFrame with column `y` (energy kWh) and `DatetimeIndex`
- `split_date` is passed for informational purposes only (splitting is done in pipeline)

## ChargingSession Schema (key columns)

Table: `evinsights."ChargingSession"`

| Column | Type | Description |
|--------|------|-------------|
| `id` | int | PK |
| `plug_in_datetime` | timestamptz | Session start (UTC) |
| `plug_out_datetime` | timestamptz | Session end (physical disconnect) |
| `charge_end_datetime` | timestamptz | End of active charging (may differ from plug_out) |
| `energy_supplied` | float | kWh delivered |
| `fk_charging_station_id` | int | FK → ChargingStation |
| `fk_dataset_id` | int | FK → Dataset |
| `fk_user_id` | int | FK → User (nullable) |

Duration: `charge_end_datetime − plug_in_datetime` preferred; fallback to
`plug_out_datetime − plug_in_datetime` when charge_end is NULL.

## Data Quality Rules

| Rule | Where enforced |
|------|---------------|
| Remove rows with `NaT` in `plug_in_datetime` | `Forecast.check_data()` / `PredictionTargetStrategy.check_data()` |
| Outlier clip: ±3 σ on scaled input | `KerasTimeSeriesBaseStrategy._scale_and_create_sequences()` |
| COVID gap exclusion | `fetch_daily_energy_for_forecast(exclude_covid=True)` or `exclude_range` in pipeline |
| `asfreq('D').fillna(0)` for daily aggregation | In data_fetcher — zero-fill missing days |
